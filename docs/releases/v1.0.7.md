## Kaarnegar 1.0.7

Kaarnegar is now available for Linux as well as Windows.

### What's new

- Linux x64 downloads: an AppImage to run without installation and a Debian package for Ubuntu, Debian, and compatible distributions.
- Linux uses a PNG tray icon. The Windows startup checkbox is shown only on Windows.
- GitHub Actions builds Windows and Linux from the same release commit and publishes their downloads with combined SHA-256 checksums. Tag builds skip tests.

All time tracking, organizations, projects, currencies, PDF reports, and backup features from 1.0.6 are included.

### Upgrading

Quit the previous version from the system tray before installing or opening this release. Your existing work history and preferences remain on your computer. Use a backup exported from Settings to move your work history between computers.

### Downloads

- **Windows installer:** `Kaarnegar-Setup-1.0.7.exe`
- **Windows portable:** `Kaarnegar-1.0.7.exe`
- **Linux AppImage:** `Kaarnegar-1.0.7-x86_64.AppImage`
- **Linux Debian package:** `Kaarnegar-1.0.7-amd64.deb`
- **Checksums:** `SHA256SUMS.txt`

For the AppImage, make the downloaded file executable with `chmod +x Kaarnegar-1.0.7-x86_64.AppImage`, then open it. Its runtime requires FUSE 2. To install the Debian package, run `sudo apt install ./Kaarnegar-1.0.7-amd64.deb`.

Linux tray visibility depends on your desktop's application indicator support. Opening Kaarnegar again restores its running window if the tray is hidden. Automatic startup from Settings is available on Windows.

No Node.js, separate font installation, account, or internet connection is required to use the app.
