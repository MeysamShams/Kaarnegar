## Kaarnegar 1.0.8

This release brings together the changes since 1.0.5 and adds Linux downloads alongside Windows.

### What's new

- Edit the start and end dates and times of saved entries, or adjust the start time of a running or paused timer. Paused time remains excluded from work duration and earnings.
- Manual entries calculate duration and earnings from their clock times, including work that crosses midnight. Older entries offer a suggested interval that you can adjust.
- Find previous tasks while typing and reuse their organization and project. Suggestions stay closed until you interact with the title field.
- PDF reports use the **Work summary report** (**گزارش میزان کارکرد**) title. The export error is fixed, and filenames use English digits and one underscore between dates, such as `1405-07-01_1405-07-30.pdf`.
- The calendar stays within the window when opened from a modal. Organization, project, date, and search filters share one row on desktop. The extra offline message has been removed from the timer card.
- Linux x64 is available as an AppImage or Debian package. Linux uses a PNG tray icon; the automatic startup setting remains available on Windows.

### Upgrading

Quit the previous version from the system tray before installing or opening this release. Your existing work history and preferences remain on your computer. Export a backup from Settings if you want a separate copy or need to move your data to another computer.

### Downloads

- **Windows installer:** `Kaarnegar-Setup-1.0.8.exe`
- **Windows portable:** `Kaarnegar-1.0.8.exe`
- **Linux AppImage:** `Kaarnegar-1.0.8-x86_64.AppImage`
- **Linux Debian package:** `Kaarnegar-1.0.8-amd64.deb`
- **Checksums:** `SHA256SUMS.txt`

For the AppImage, run `chmod +x Kaarnegar-1.0.8-x86_64.AppImage` before opening it. The AppImage runtime requires FUSE 2; use the Debian package if your system does not provide it. Install the Debian package with `sudo apt install ./Kaarnegar-1.0.8-amd64.deb`.

Linux tray visibility depends on your desktop's application indicator support. Opening Kaarnegar again restores its running window if the tray is hidden. No Node.js, separate font installation, account, or internet connection is required to use the app.
