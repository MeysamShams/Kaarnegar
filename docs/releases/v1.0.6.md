## Kaarnegar 1.0.6

This release makes time entries easier to adjust and improves PDF reports.

### What's new

- Edit the start and end dates and times of saved entries. Adjust the start time of an active timer, including while it is running. Paused time stays excluded from work duration and earnings.
- Type a task title or choose a matching previous task. Suggestions include the organization and project and fill them in when selected.
- Manual entries calculate work duration and earnings automatically from start and end times, including overnight work.
- PDF reports use **Work summary report** (**گزارش میزان کارکرد**) as their title. Organization/project text and the tagline have been removed.
- PDF filenames use English digits and a single underscore between dates, for example `1405-07-01_1405-07-30.pdf`. Persian reports continue to use Jalali dates.

Older entries only stored duration. Their edit form offers a suggested time interval that you can adjust before saving.

### Upgrading

Quit the previous version from the system tray before installing or opening this release. Your existing work history and preferences remain on your computer. Export a backup from Settings if you want a separate copy of your data.

### Downloads

- **Installer:** `Kaarnegar-Setup-1.0.6.exe`
- **Portable:** `Kaarnegar-1.0.6.exe`
- **Checksums:** `SHA256SUMS.txt`

Windows x64. No Node.js, separate font installation, account, or internet connection is required to use the app. For portable startup, keep the executable in a stable location.
