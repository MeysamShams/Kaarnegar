## Kaarnegar 1.0.4

This release streamlines PDF reports and fixes Windows startup settings.

### What's new

- **Simpler PDF reports:** The report summary uses the corrected Persian label «میزان کارکرد». The separate task summary table is gone. Time entry details show the task, optional project, and date without organization names, entry type, duration, rate, or earnings columns.
- **Windows startup fix:** Enabling **Launch at Windows startup** now checks Kaarnegar's named startup entry correctly, including portable builds and paths with spaces.
- **Better select controls:** Dropdown arrows have consistent spacing in Persian and English, including settings, filters, and calendar controls.
- **Updated wording:** Persian report text and translations are clearer, and the outdated calendar and font phrase has been removed from the report preview.
- **Updated screenshots:** The README shows English screenshots with a complete sidebar and the Meysam Shams profile.

### Upgrading

Quit the previous version from the system tray before installing or opening this release. Your existing work history and preferences remain on your computer. Export a backup from Settings if you want a separate copy of your data.

### Downloads

- **Installer:** `Kaarnegar-Setup-1.0.4.exe`
- **Portable:** `Kaarnegar-1.0.4.exe`
- **Checksums:** `SHA256SUMS.txt`

Windows x64. No Node.js, separate font installation, account, or internet connection is required to use the app. For portable startup, keep the executable in a stable location.
