## Kaarnegar 1.0.3

Track work by organization and project, choose your currency, and use Kaarnegar in English or Persian.

### What's new

- **Organizations and projects:** Create organizations with multiple projects. Every new time entry requires an organization; selecting a project is optional.
- **Organization and project rates:** Set an organization's hourly rate or override it for a project. A blank project rate inherits the organization's rate. Saved entries and running timers keep their recorded rates.
- **Multiple currencies:** Choose IRT, IRR, USD, EUR, GBP, CAD, AUD, AED, CHF, JPY, or TRY for an organization. Reports show separate totals for each currency; no currency conversion is applied.
- **Filtered reports and PDFs:** Filter by organization, project, date range, and task title. PDF exports include the matching entries and organization/project details.
- **English and Persian:** English is the default for new installations. Choose Persian in Settings for the RTL interface and Jalali dates, or English for LTR layout and Gregorian dates. The tray menu and PDF reports follow your language.
- **Light, Dark, and System themes:** A new charcoal-and-teal dark theme covers the dashboard, reports, calendar, dialogs, and compact timer.
- **Launch at Windows startup:** Enable the checkbox in Settings to open Kaarnegar when you sign in. Installed and portable builds are supported.
- **Remembered window mode:** The app restores compact/full mode, window size, position, and maximization after restarting.
- **Updated documentation:** A new English README explains setup, workflows, data storage, and development.

### Upgrading

Existing history is moved into a **General** organization, preserving its original rates, durations, and toman currency. Saved language choices remain unchanged. Organizations and projects are included in JSON backups.

Quit the previous version from the system tray before installing or opening this release. Export a backup from Settings if you want a separate copy of your history.

### Downloads

- **Installer:** `Kaarnegar-Setup-1.0.3.exe`
- **Portable:** `Kaarnegar-1.0.3.exe`
- **Checksums:** `SHA256SUMS.txt`

Windows x64. No Node.js, separate font installation, account, or internet connection is required to use the app. For portable startup, keep the executable in a stable location.
